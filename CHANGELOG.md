# Changelog

## 0.1.2

- Add enabled-by-default MAC address diagnostic sensors for the router, satellites and clients.
- Keep MAC addresses visible for disconnected clients, using existing stable identifiers.
- Correct the integration version reported in downloadable diagnostics.

## 0.1.1

- Include a custom router-and-mesh icon with standard, high-resolution and dark variants.
- Display the icon in Home Assistant using bundled local brand assets.

## 0.1.0

- Local read-only AX10 and C64 EasyMesh monitoring.
- UI setup, options, reconfiguration and reauthentication in English/Hebrew.
- Router/port/satellite/client entities and stable MAC-derived identifiers.
- Shared polling, optional endpoint handling, identity-redacted diagnostics.
- Isolated Home Assistant development container, synthetic tests and HACS packaging.
